Google Sheets

Obtener API Key y Sheet ID

  1. Ve a console.cloud.google.com y crea o usa un proyecto existente.
  2. En APIs y servicios → Biblioteca, activa "Google Sheets API".
  3. En Credenciales → + Crear credenciales → Clave de API, copia la clave generada.
  4. En la URL de tu Sheet: spreadsheets/d/ID/edit
  5. Asegúrate de que la hoja tenga acceso "Cualquier persona con el enlace".
